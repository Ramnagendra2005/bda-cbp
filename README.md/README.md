# OmniData Holding — Big Data Analytics

This repository contains the OmniData Holding batch-processing project for telecom customer analytics, churn analysis, and business-risk reporting.

## Live Dashboard

[Open the deployed Big Data Dashboard](https://bigdata-dash-rjltdss6.manus.space)

## Contents

- `Project.ipynb`: exploratory analysis notebook.
- `hive_commands.sql`: Hive queries used for analytics.
- `Telco.csv`, `risk.csv`: source datasets.
- `Hive p/`: exported analysis results and supporting CSV files.
- `Big_Data_Project_Proposal_OmniData_Holding.docx`: project proposal.
- `hdfs.jpeg`: HDFS-related project visual.

Generated Spark output folders and temporary runtime artifacts are intentionally excluded from this repository.
